# Retained interactive image templates

Cached history recovery accepts a typed native JPEG header with an ordinary body,
optional footer and one validated `cta_url` button. It preserves the full header,
footer and native flow in provider history metadata. The visible projection retains
the body, a distinct image caption, footer and button label/URL; it executes no action.
The persisted native source and message key remain unchanged.

The JPEG descriptor retains bounded canonical base64 thumbnail bytes and the complete
thumbnail hash/hash/direct-path triple. Thumbnail metadata is never a download target
or a substitute for the full file's SHA-256 and length. Unknown nodes, unsafe actions,
malformed metadata and incomplete thumbnail pointers remain unsupported. Actual media
recovery still requires the existing account, native owner, direction, canonical
binding and independent physical byte checks; parsing a template proves no file
availability.
